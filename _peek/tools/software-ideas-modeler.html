Software Ideas Modeler

Tool

Software Ideas Modeler is a CASE and an UML tool. The modeler supports all 14 diagram types specified in UML 2.5. It also supports among others the following diagrams and standards:ER diagrams BPMN 2.0 CMMN SysML 1.5 ArchiMate 3 JSD CRC flowcharts data flow diagram Infographics Wireframes Mind maps…
